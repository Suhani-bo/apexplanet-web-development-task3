# Bloom & Build — Suhani's Task 3 Website

A responsive, pastel-themed portfolio-style website created for ApexPlanet Task 3: **Advanced Styling and JavaScript**.

## Included Task 3 requirements
1. **Responsive design using media queries** — layout adapts for desktop, tablet and mobile.
2. **Interactive JavaScript project** — a 3-question web basics quiz with answer feedback, score tracking and replay.
3. **Image carousel** — previous/next buttons and clickable dots.
4. **Fetch data from a public API** — loads a random joke from `official-joke-api.appspot.com`; a fallback message appears if the API is unavailable.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — pastel styling, responsive layouts and animations
- `script.js` — quiz, carousel, mobile navigation and API fetch
- `README.md` — project notes

## How to run
1. Extract the ZIP.
2. Open the extracted folder in VS Code.
3. Open `index.html` in a browser. You can use the **Live Server** extension for the best development experience.
4. Internet access is needed for Google Fonts, carousel photos and the public joke API.

## Customize before submission
- Check the name, college and skills in `index.html`.
- Add your own email/contact details if you want them shown.
- Add screenshots of your working website to your task submission if required.
